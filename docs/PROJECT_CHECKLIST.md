## 1. 시뮬매니저 (본 프로젝트, 192.168.0.10)

### 1.1 Modbus TCP 통신 및 UI 개발

- [x] 레지스터 맵 SSOT 코드화 — 링크①(Coil 6·HR 12·DI 4·IR 19)·②·③(IR 12·DI 3·HR 6·Coil 2) 전체, `protocol/`
- [x] 스케일 encode/decode(×10/×100/×1000/×50, INT16 부호)·32-bit big-endian 결합 함수
- [x] 링크①(EMS용)·링크③(RTDS용) Modbus TCP Server 2식 — pymodbus 비동기
- [x] 뱅크 라우팅 — single_port(클라이언트 IP 구분) / per_link_port(①7000·③5021) 두 모드
- [x] read/write 후킹 — 클라이언트 쓰기 감지 → 이벤트 발행(연결중개·HB·ack 트리거)
- [x] 링크① DI/IR HR 미러 — EMS 쓰기용 미러 HR 영역 → DI/IR 뱅크 내부 매핑
- [x] Heartbeat 생존감시 — ①IR 300000(EMS)·③HR 400000(RTDS), 실 1 s / 판정 3 s
- [x] REST API + WebSocket 스트림 — 시계 제어·상태·실시간 계측
- [x] 대시보드 UI — 가상시각·구간, 노드 연결상태 카드, 실시간 차트(전력 3계열+SOC), 시퀀스 로그, Run 제어
- [x] 데이터 대시보드 UI — 부하·기상 CSV 업로드, 차트, 필터·정렬
- [x] 0.0.0.0 바인딩 — 타 PC 브라우저 접속 지원

### 1.2 동작 시퀀스 등 기능 구현

- [x] 가상시계·가속엔진 — 자유진행(free-running), 시작/정지/일시정지/되감기, 1분/15분/일 경계 틱, 구간 인덱스 0~95
- [x] 시나리오 배포 — 1분 틱마다 ①HR 400000~/③IR 300000~ 갱신, ZOH/선형 보간, 일사 MJ/m²→W/m² 환산(×277.8)
- [x] 구간 경계 원자성 — 시각·기상 갱신 **후** 구간 인덱스(①HR 400006) 갱신
- [x] P1 연결중개 — ③Coil 000000 'RTDS 운전중'=1 감지 → ①Coil 000004 'RTDS 준비됨'=1
- [x] P2 초기 SOC 핸드셰이크 — ③IR 300011 세트 → ③DI 100000 트리거 → RTDS 주입 → ③Coil 000001 ack (최초 기동에만)
- [x] P3 운전 개시 / P5 종료(30일차 구간 95 → 시계 정지 → 최종 SOC 취득·보존)
- [x] P6 케이스 전환 — 리셋 신호, 시계 되감기, 시나리오 포인터 리셋, 시나리오 ID 변경
- [x] §3.8 Late-join/Rejoin — 재접속 시 SOC 트리거 미세트, 현재 환경 즉시 제공
- [x] §6 예외 — 단절 이벤트 기록(시계는 계속), 단절 누적 카운트, '일시정지'는 운영자 전용
- [x] 기상 이벤트 주입 — 폭염·폭설 운영자 편집 UI/API, 양 Run 동일 적용
- [x] Historian — SQLite(runs·measurements_1m·forecast_blocks_15m·sequence_log 등), Run 태깅
- [ ] Run A/B 오케스트레이션 — A→P6→B 자동 진행, 동일 조건 검증, Run 무효 판정 (Phase 6)
- [ ] 예측-실적 페어링(B-9) — 구간 실측 확정치 vs 직전 구간 h=1 예측 매칭 적재(설계서 v1.7) (Phase 6)
- [ ] §7 평가·비교 리포트 — 피크·요금(TOU)·예측률(MAPE/nMAE/RMSE/Bias) 산정, A vs B 비교 UI, CSV/Excel 내보내기 (Phase 6)

### 1.3 단위 기능 시험

- [x] 스케일·부호 변환 단위 테스트 — INT16 음수, ×10/×100/×1000/×50 왕복, UINT32 상위워드 우선
- [x] 가상시계 환산·구간 랩어라운드(96) 테스트
- [x] 원자성 순서 테스트 — 구간 인덱스 변화 시점에 시각·기상이 이미 신규 값

- [x] 에뮬레이터 기반 통합 테스트 — P1→P2→P3→P4 왕복(CMD/RES Seq, 지령 추종, echo, SOC 상승) 자동 검증

## 2. EMS (외부 노드, 192.168.0.20)

### 2.1 통신(Client) 및 UI 설계·개발

- [ ] 링크① Client — 시뮬매니저(Server) 접속: 시각·기상·이벤트 읽기(①HR/DI/IR), 가상 1분 주기 폴링
- [ ] 링크① 예측 블록·상태 기록 — DI/IR 직접 쓰기 불가 → **HR 미러 주소로 FC16 기록** (미러 오프셋 시뮬매니저와 합의 필수)
- [ ] 링크② Client — RTDS(Server) 접속: P/Q 지령·제어모드·워치독 쓰기(②HR/Coil), 계측·상태 읽기(②IR/DI)
- [ ] 링크별 독립 TCP 세션 병행 (직렬화 금지) — 폴링 주기: 가상 1분 = 실 (가속배율/15) 초 대응
- [ ] 스케일·부호 정합 — 링크② 전력 ×100, 방전 +/충전 −, big-endian (protocol 맵 v1.0 기준)
- [ ] Heartbeat 기록 — ①IR(미러) 300000 실 1 s 증가
- [ ] 워치독 기록 — ②HR 400010 가상 1분마다 +1
- [ ] 통신 예외 처리 — 응답 타임아웃 1,000 ms·재시도 3회·재접속 1~5 s
- [ ] EMS 운영 UI — 예측·스케줄·지령 현황, 연결상태, 계측 모니터링 화면

### 2.2 AI 예측 및 제어 모델 개발 (계획용, 제어용)

- [ ] 예측 입력 파이프라인 — 링크① 기상(기온·풍속·습도·일사·전운량 등) + 링크② 계측 이력 수집·저장
- [ ] PV 발전 예측 모델 — 일사·온도 기반, 정격 150 kW 상한 (내부 예측 지평 자유 — 통신 전달은 [1구간]만, 설계서 v1.7)
- [ ] 부하 예측 모델 — **자체 예측 필수** (부하 실측 ③IR 300008은 RTDS에만 전달, EMS는 블라인드)
- [ ] 계획용(스케줄링) 최적화 — 15분 96구간 일 단위 충방전 스케줄, 피크저감·요금절감 목적
- [ ] 제어용 모델 — 구간 경계마다 예측 갱신 → P 지령 산출, SOC 상하한 90/10%·충방전 제한 250 kW 제약
- [ ] Run A 규칙기반 운영 — TOU 규칙표(§5.1: 23~09시 충전, 최대부하 시간대 방전)
- [ ] Run B 기상 기반 최적 운영 — 예측 기반 피크저감 최적화 (제어모드 ②HR 400000=3)
- [ ] 웜업 처리 — Run 시작 초기 1일 예측 이력 부족 구간 운영 방안
- [ ] P6 전환 시 예측 이력 버퍼 초기화 (사전 학습 모델 파라미터는 유지)

### 2.3 운영 시퀀스 및 기능 구현

- [ ] P1 — ①Coil 000004 'RTDS 준비됨'=1 확인 후 RTDS(링크②) 직결 접속
- [ ] P3 — ①Coil 000005·000000 운전 개시 감지 → 제어모드 설정 → 지령 루프 시작
- [ ] 구간 경계 처리 — ①HR 400006 구간 인덱스 변화 감지 → 시각·기상 일괄 읽기(원자성은 매니저가 보장)
- [ ] 지령 원자성 — 데이터 블록(P/Q 지령 등) 기록 완료 후 **마지막에** CMD Seq(②HR 400011) +1
- [ ] 지령-echo 검증 — 기록값 vs ②IR 300031/300032 대조, 불일치 3회 지속 시 알람·재기록(CMD Seq +1)
- [ ] 예측 블록 기록 — 기준 구간 + [1구간] PV/부하 예측·스케줄·목표 SOC(①IR 300003~300006, 300007~300018은 예약 0 기록) → ①IR 미러 영역, 15분마다
- [ ] P5 종료 — ①Coil 000001 감지 → 지령 중지 / P6 리셋 — 시나리오 ID(①HR 400007) 변화 대응
- [ ] RTDS 단절 대응 — ①Coil 000004=0 감지 → 지령 중단·계측 결손 표시
- [ ] Late-join — 임의 시점 접속 시 현재 가상시각·구간 기준 합류(미접속 구간 소급 없음)
- [ ] PCS 고장 대응 — 경알람 → 고장 리셋(②Coil 000005) 1회 / 중알람 → E-Stop(②Coil 000002)

## 3. RTDS (외부 노드, 192.168.0.30)

### 3.1 모델 구현 (PV, 부하, ESS 등)

- [ ] PV 모델 — 일사·온도·적설 함수, 정격 150 kW (③IR 환경 데이터 입력)
- [ ] 부하 모델 — ③IR 300008 부하 실측값 재생
- [ ] ESS/배터리 모델 — 500 kWh, SOC 적분(충방전 효율 반영), SOC 1% = 5 kWh
- [ ] PCS 모델 — 정격 250 kW(가정, OPEN_ISSUES #3), P 지령 추종(램프), 충방전 제한
- [ ] PCC(수전점) 모델 — 수전/역송 = 부하 − PV − P_ESS
- [ ] 계측 산출 — 전압·전류·주파수·역률·누적 전력량(32-bit) 등 링크② IR 전 항목
- [ ] 초기 SOC 주입 기능 — 지정 값(50%)으로 배터리 상태 리셋
- [ ] 고장 모의 기능 — 경알람·중알람(과온·지락) 상태 천이 (예외 시험용)

### 3.2 통신 (Server, Client) 구현

- [ ] 링크② Server — EMS Client 수용: 지령·제어모드·워치독 수신(②HR/Coil), 계측·상태 제공(②IR/DI), 레지스터 맵 전체
- [ ] 링크③ Client — 시뮬매니저(Server) 접속: 환경·시나리오 읽기(③IR/DI), HB·결과 기록(③HR/Coil)
- [ ] 스케일·부호 정합 — 링크② ×100 / 링크③ 전력 ×10·온도 ×100, 방전 +/충전 −, big-endian
- [ ] 32-bit 누적 전력량 — ②IR 300033~300036, 상위워드 우선, 하위워드 ×10 kWh
- [ ] Heartbeat 기록 — ③HR 400000 실 1 s 증가
- [ ] Historian용 결과 기록 — ③HR 400002~400005 (ESS 전력·SOC·PCC 수전·역송, 가상 1분 주기)
- [ ] 통신 예외 처리 — 응답 타임아웃 1,000 ms·재시도 3회·재접속 1~5 s
- [ ] 링크②·③ 독립 세션 병행

### 3.3 운영 시퀀스 및 기능 구현 (입력, 지령, 출력 등)

- [ ] P1 — 기동 완료 시 ③Coil 000000 'RTDS 운전중'=1 기록
- [ ] P2 초기 SOC 핸드셰이크 — ③DI 100000 트리거=1 감지 → ③IR 300011 값 주입 → ③Coil 000001 ack=1 → 트리거 해제 확인 후 ack 해제
- [ ] P3 — ③DI 100001 운전 개시 감지 → 모델 연산·지령 추종 시작
- [ ] 지령 래치 원자성 — CMD Seq(②HR 400011) 변화 시에만 지령 블록 일괄 래치
- [ ] RES Seq·echo — 지령 적용 후 ②IR 300031/300032 echo 기록, RES Seq(②IR 300000) 마지막에 +1
- [ ] 워치독 감시 — ②HR 400010 3주기(가상 3분) 정체 시 PCS 안전상태(P=0) 천이
- [ ] EMS 단절 시 자체 안전 — 워치독 정체 기반 P=0 (매니저 ③IR 300003 'EMS 상태'=0 참조 가능)
- [ ] P5 종료 — 최종 SOC 제공 / P6 리셋 — ③DI 100002 감지 → 모델·상태 초기화
- [ ] Late-join — 재접속 시 SOC 트리거 없이 현재 환경 기준 합류
- [ ] PCS 고장 처리 — 고장 리셋(②Coil 000005)·E-Stop(②Coil 000002) 수신 동작

## 4. 공통 (3팀 합동)

### 4.1 링 구조 통신 시험 (시뮬매니저–EMS–RTDS)

- [ ] 사전 합의 확정 — 포트 구성(single_port IP 라우팅 vs 링크별 포트), Unit ID, 링크① DI/IR **HR 미러 오프셋**, PCS 정격 (OPEN_ISSUES #1·#2·#3)
- [ ] 네트워크 환경 — 3 PC IP(192.168.0.10/20/30) 고정, 방화벽 인바운드(Modbus 포트·웹 8100) 개방, ping 상호 확인
- [ ] 링크① 단독 시험 — EMS→매니저: 시각·기상 읽기, HB·예측 블록(미러 HR) 쓰기, 값·스케일 대조
- [ ] 링크② 단독 시험 — EMS→RTDS: P/Q 지령 쓰기·echo 확인, 계측 읽기, 스케일(×100)·부호 대조
- [ ] 링크③ 단독 시험 — RTDS→매니저: 환경 읽기, HB·결과 쓰기, 스케일(×10/×100) 대조
- [ ] 3링크 동시 병행 — 링크별 독립 세션, 상호 간섭·지연 없음 확인
- [ ] 스케일·부호 교차 검증 — 동일 물리량(온도·적설 등) 링크별 상이 스케일 정합, 방전 +/충전 − 일치
- [ ] Seq 원자성 검증 — CMD/RES Seq 변화 시점의 블록 정합, 구간 인덱스 갱신 순서
- [ ] 단절·복구 시험 — 케이블 분리/노드 재시작 → 3 s 판정, 재접속 1~5 s, Late-join 합류
- [ ] 가속배율별 폴링 부하 시험 — 목표 배율(실 10 s = 가상 15분)에서 1분 계측 결손 없음
