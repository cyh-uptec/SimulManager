# 미결정(협의 필요) 항목

> EMS·RTDS측(외부)과 합의가 필요하거나 실사양 확정 대기 중인 항목.
> 결정되면 상태를 갱신하고, 관련 코드·`docs/PROTOCOL_RULES.md`·`docs/DEVELOPMENT_PLAN.md`에 반영한다.

| # | 항목 | 상태 | 내용 · 잠정 대응 |
|---|---|---|---|
| 1 | 링크①·③ 동일 주소 충돌 | ✅ 내부 방침 확정 (2026-08-07) | 매니저가 두 링크 모두 Server(502/Unit 1)인데 ①Coil 000000(운전시작) ≠ ③Coil 000000(RTDS 운전중). → **구현 완료(Phase 2)**: `single_port` 모드 = 클라이언트 IP 라우팅 프록시(`modbus/server.py` RoutingProxy), `per_link_port` 모드 = ①7000/③5021 분리. **방침 확정: 운영 = single_port(502)·시험/개발 = per_link_port(①7000/③5021, 2026-08-11 EMS측 요청으로 ①=7000)** — 설정 UI(⚙ 설정→네트워크)로 전환. 잔여: EMS·RTDS측 통보(단일 포트 조건: 양 노드 정적 IP 상이) |
| 2 | 링크① DI/IR 쓰기 방향 | 🔶 합의 대기(문서 반영 완료) | Modbus 규격상 Client(EMS)는 DI/IR에 쓸 수 없음(설계서 §8). → **구현 완료(Phase 2)**: 옵션(b) HR 미러 — DI n↔HR(10000+n) 참조 410000대, IR n↔HR(30000+n) 참조 430000대 (`protocol/mirror.py`). **문서 반영 완료(2026-08-03)**: 프로토콜맵 v1.1 시트1에 '미러 HR 참조' 열·규칙 추가(누락 IR 300007~300018도 보완), 설계서 v1.6 §2.1·§8에 확정 반영. 잔여: 미러 오프셋(+10000/+30000) EMS측 최종 합의 |
| 3 | PCS 정격 250 kW 가정 | 🔶 실사양 대기 | 확정 시 설계서 §1.2·§5 수치, ②HR 400008/400009 설정값 갱신. 250 kW 초과 사양이면 ②HR 400001 범위 협의(스케일 변경 또는 INT16 ±327.67 한계 검토) 선행 필요 |
| 4 | 시나리오 원본 데이터 포맷 | 🔶 데이터 대기 | 1개월 실측 기상·부하 데이터의 파일 포맷/해상도 미확정. → CSV 임포터 + 샘플 생성기로 선개발, 15분→1분 보간은 ZOH/선형 선택(두 Run 동일 적용) |
| 5 | 가속배율 하향(1~5 s) 시 폴링 | ⬜ 검토 예정 | 가상 1분 폴링이 응답시간에 근접 → 15분 경계 이벤트만 유지하고 1분 계측을 실시간 최대속도 폴링으로 대체하는 협의(설계서 §8). Phase 7 성능 실측 후 결정 |
| 6 | 기상 이벤트(폭염·폭설) 주입 방식 | ✅ 방향 확정 (2026-07-06) | 실측 기상 데이터에 적설량 항목이 없고 이벤트 발생일이 데이터 기간과 무관하므로, **운영자가 임의 입력(주입)** 하는 방식으로 확정 — Phase 3에서 이벤트 편집 UI/API 구현: 기상 상태코드(①HR 400011/③IR 300007 — 0정상/1폭염/2폭설)와 적설량(①HR 400010/③IR 300006)을 가상 기간·구간 지정으로 오버라이드. 양 Run 동일 적용(공정 비교) |
| 7 | 일사 단위 | ✅ 종결 (2026-07-06 재개정) | 프로토콜맵 v1.0에서 일사량 레지스터(①HR 400008/③IR 300004) 단위가 **MJ/m²로 변경** → 매니저는 실측값을 환산 없이 그대로 배포(기존 W/m² 환산 삭제). W/m² 환산은 각 노드(EMS 예측·RTDS PV 모델) 내부 책임 |
| 9 | 일사량 ×1 스케일 분해능 | 🔶 협의 권장 | 시간당 일사 실측은 0~4 MJ/m² 수준인데 레지스터 스케일이 ×1(정수)이라 반올림 시 분해능 손실이 큼(예: 1.8→2). **×100(0.01 MJ 분해능, 범위 0~655.35)** 으로 스케일 변경을 EMS·RTDS측과 협의 권장 — 확정 시 protocol SSOT 한 곳만 수정하면 됨 |
| 8 | P2 완결 전 P3 개시 허용 여부 | 🔶 협의 후보 | 현 구현은 자유진행 원칙에 따라 SOC 주입 트리거 세트 직후 운전을 개시(비차단) — RTDS가 주입 완료 전 첫 구간이 시작될 수 있음. 설계서 §3.2는 "Run 시작 전 완료 권장, 필수 아님". RTDS측과 허용 여부 확인 권장 |

상태 범례: 🔶 대기 · 🔄 협의 중 · ✅ 확정(결정 내용과 반영 커밋/파일 기록)
